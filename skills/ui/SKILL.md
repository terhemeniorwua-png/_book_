# UI skill

- Build responsive apartment discovery and reservation experiences with the Next.js App Router, TypeScript, and Tailwind CSS v4.
- Preserve semantic HTML, keyboard operation, visible focus, accessible labels, and useful loading, empty, and error states.
- Fetch canonical apartment, price, and availability data from the versioned API; the client cannot be authoritative for reservation decisions.
- Validate interactive form values with Zod and keep secrets out of client bundles.
- Do not create booking pages or product flows until their phase is active and acceptance criteria are defined.
